# Real Pheasant, no model

From the repository root:

```text
docker compose -f deploy/stub/compose.yaml up -d --wait
uv run python scripts/check_pheasant_setup.py
```

See [setup](../../docs/setup.md#2b-test-real-pheasant-without-a-model) for the
walkthrough. This is a dedicated SQLite instance on port 8766 with persistent
workspace, state, memory, and export volumes. No model credentials are passed
into the container. The lab is not mounted as an indexed source.

`pheasant.yaml` was generated by Pheasant 0.12.5 from `answers.json`, adapted
from its `local-small` preset. To regenerate after editing the answers, use
Pheasant's wizard so every key is validated by the installed schema.

PowerShell, from the repository root:

```powershell
$stubConfigDir = (Resolve-Path deploy/stub).Path
docker run --rm --entrypoint python --mount "type=bind,source=$stubConfigDir,target=/output" ghcr.io/esatt10/pheasant:0.12.5 -m pheasant setup --answers /output/answers.json --accept-defaults --plain --target docker --output /output/pheasant.yaml --force
```

macOS/Linux, from the repository root:

```bash
docker run --rm --entrypoint python --mount "type=bind,source=$(pwd)/deploy/stub,target=/output" ghcr.io/esatt10/pheasant:0.12.5 -m pheasant setup --answers /output/answers.json --accept-defaults --plain --target docker --output /output/pheasant.yaml --force
```

Validate the generated configuration before starting:

```text
docker compose -f deploy/stub/compose.yaml config --quiet
docker compose -f deploy/stub/compose.yaml run --rm --no-deps pheasant doctor -c /config/pheasant.yaml --no-require-paths
```

The lab registers the server's submission directory as a `document_folder`,
syncs it, acknowledges indexed documents, and reads each item's receipt. Search
previews are expanded through `get_file_summary`; receipt IDs connect returned
artifacts to the original lab sources. The pinned lab map enables MCP snapshot
arguments advertised by 0.12.5. The general live example leaves those optional
arguments unmapped for compatibility with older versions.

Stop with `docker compose -f deploy/stub/compose.yaml stop`; restart with the
same `up -d --wait` command. These commands preserve the volumes and memories.
